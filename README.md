# ✦ Polychromatica

### Um universo de arte, cores e fantasia.

A **Polychromatica** é um portfólio artístico desenvolvido para apresentar obras visuais em uma experiência digital elegante, intuitiva e responsiva. Inspirado na estética vintage fantástica, o projeto combina tons de lilás, turquesa e elementos delicados para criar uma identidade visual própria.

🔗 **Acesse o site:** [polianam06.github.io/Polychromatica](https://polianam06.github.io/Polychromatica/)

---

## 🎨 Sobre o projeto

O projeto foi desenvolvido do zero utilizando HTML, CSS e JavaScript, com o objetivo de construir uma página única que valoriza as obras artísticas e proporciona uma navegação agradável em diferentes dispositivos.

A interface reúne uma apresentação do projeto, uma galeria de criações e uma seção de contato, explorando recursos de desenvolvimento front-end e princípios de responsividade.

## ✨ Funcionalidades

- **Página única:** navegação organizada entre as principais seções do site.
- **Galeria artística:** exibição de 20 obras em uma apresentação visual organizada.
- **Visualização ampliada:** abertura das obras em uma janela de ampliação (*lightbox*).
- **Navegação entre obras:** controles para visualizar a imagem anterior e a próxima.
- **Contador de imagens:** indicação da posição da obra atual na galeria.
- **Atalhos de teclado:** navegação pelas setas esquerda e direita e fechamento com `Esc`.
- **Design responsivo:** adaptação para notebooks, tablets e celulares.
- **Identidade visual personalizada:** combinação de cores e tipografia inspirada no estilo vintage fantástico.
- **Seção de contato:** acesso aos canais de comunicação do projeto.

## 🗂️ Estrutura do projeto

```text
Polychromatica/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── imagens/
    ├── obra-01.jpg
    ├── obra-02.jpg
    └── ...
```

> A pasta `imagens/` contém os arquivos das obras. Os nomes acima são exemplos ilustrativos; os arquivos reais devem manter seus nomes atuais.

## 💻 Como executar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/polianam06/Polychromatica.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Polychromatica
   ```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no Visual Studio Code.

Não é necessário instalar dependências para executar a versão estática do projeto.

## 📱 Responsividade

O site foi testado em diferentes tamanhos de tela, incluindo notebook, tablet e celular, com atenção à organização da galeria, à legibilidade dos textos e à navegação.
